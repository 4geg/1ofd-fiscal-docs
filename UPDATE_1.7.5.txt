1OFD Fiscal Docs 1.7.5

Основные изменения:
- select-стрелки больше не исчезают после открытия списка;
- новые кнопки экспорта CSV/JSON;
- непрозрачные sticky-заголовки таблицы;
- scrollbar карточки ФД остаётся внутри скруглённого окна;
- служебные данные ОФД/ФНС перенесены в «Дополнительные данные ФД»;
- ФД можно открыть в отдельной вкладке;
- Windows EXE получает метаданные версии, asInvoker manifest, --noupx и SHA256SUMS.txt в Release.

Перед коммитом обязательно проверь локального автора Git — только 4geg.
