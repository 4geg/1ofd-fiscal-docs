# 1OFD Fiscal Docs

**Версия:** 1.7.3  
**Автор:** 4geg

**Скачать последнюю Windows-версию:** [1OFD_FiscalDocs.exe](https://github.com/4geg/1ofd-fiscal-docs/releases/latest/download/1OFD_FiscalDocs.exe)

## Как пользоваться

1. Запусти `1OFD_FiscalDocs.exe`.
2. Приложение появится в системном трее и само откроет веб-интерфейс в браузере.
3. При первом запуске нажми **API-ключ**, вставь ключ 1-ОФД и нажми **Проверить и сохранить**.
4. Выбери период и параметры поиска, затем нажми **Запросить**.
5. Для уже загруженных документов используй блок **Поиск и фильтры по результатам запроса**.
6. Закрытие вкладки браузера **не завершает приложение**. Чтобы открыть интерфейс снова — нажми значок приложения в трее.
7. ПКМ по значку в трее: **Открыть / Скопировать ссылку интерфейса / Перезапустить / Открыть журнал / Папка данных / Завершить**.

API-ключ вводится один раз. Сохранённые ключи остаются в списке при следующих запусках. Глазом можно временно показать вводимый или сохранённый ключ; сохранённый ключ автоматически снова скрывается. В Windows ключи шифруются DPAPI и не хранятся в открытом виде.

## Что умеет

- поиск фискальных документов через Universal API 1-ОФД;
- регистрации, перерегистрации, закрытия ФН и другие типы ФД;
- поиск по РНМ, ЗН ККТ, ЗН ФН, ФД, ФПД, названию и адресу;
- быстрые параллельные запросы, кнопка **Стоп** и автоматический повтор неудачных;
- контроль полноты результата;
- локальные фильтры без повторного запроса к ОФД;
- CSV/JSON экспорт;
- дата/время в удобном формате `ДД.ММ.ГГГГ ЧЧ:ММ`;
- копирование значений из карточки фискального документа;
- просмотр полного JSON ответа API;
- несколько сохранённых API-ключей с выбором, удалением и временным просмотром;

## Запуск из исходников

Требуется Windows 10/11 и Python 3.13+.

Самый простой способ: дважды запусти `run_dev.bat`. Скрипт сам создаст `.venv`, установит зависимости и запустит приложение.

## Сборка EXE

Дважды запусти `build_exe.bat`.

После успешной сборки готовый файл будет здесь:

`dist\1OFD_FiscalDocs.exe`

Сборка использует PyInstaller в режиме `--onefile --windowed`, поэтому отдельное окно консоли не появляется. В v1.7.3 перезапуск сервера выполняется внутри текущего процесса, без запуска второго EXE.

## Где хранятся данные

Пользовательские данные и кэш находятся в:

`%APPDATA%\4geg\1OFD_Fiscal_Docs\`

Там же находится папка `logs`.

## Безопасность

- API-ключ не записывается в исходный код.
- На Windows ключ шифруется через DPAPI текущего пользователя.
- Не публикуй `config.json`, логи с секретами и реальные API-ключи в GitHub.
- `.gitignore` уже исключает стандартные локальные файлы.

## GitHub

В репозитории есть workflow `.github/workflows/build-windows.yml`. Его можно запустить вручную в GitHub Actions или автоматически при создании тега вида `v1.7.3`. Готовый EXE будет доступен как artifact сборки.

## Важные ограничения

Первичная регистрация ККТ определяется отдельно: Universal API не предоставляет для неё отдельный `transactionTypes`. Программа использует данные активации ФН и явно предупреждает, если полноту регистрации нельзя гарантировать.

Прямые ссылки на документ в личном кабинете 1-ОФД пока не используются, потому что внутренний ЛК требует отдельную браузерную сессию/Cookie/XSRF.
