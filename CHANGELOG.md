# Changelog

## 1.7.8M

- Версия в имени EXE: `1OFD_FiscalDocs_1.7.8M.exe`, одинаково для локальной сборки и GitHub Release; контрольная сумма соответствует этому имени.
- Голубая отметка одного последнего успешно просмотренного документа в списке; следующий просмотр переносит отметку.
- Кнопка «Для действий в ЛК ФНС» добавлена в локальный фильтр загруженных результатов, с тем же набором типов, что в API-фильтре.
- Отдельное обозначение M после опубликованной 1.7.8; PE-версия 1.7.8.1, строковая версия 1.7.8M. Проверка версии поддерживает M; в прежней 1.7.8 индикатор этот выпуск не распознаёт.

## 1.7.8

- Исправлен отступ между выбором профиля нагрузки и кнопкой его применения.

- Нулевые необязательные суммы скрыты в карточке; значимые нули и полный JSON сохранены.
- Русские реквизиты карточки и расширенного CSV, включая НДС 22% и маркировку позиций.
- Текущий и предыдущий результаты запросов, мягкий лимит истории 5 ГБ. Ручная очистка из трея и веба удаляет все результаты вместе с текущим и останавливает активный запрос.
- Немедленное принудительное завершение из трея с записью числа активных HTTP-запросов.
- Профили, ручные параметры и лимит журнала перенесены в НАСТРОЙКИ в шапке; отдельный параллелизм фильтра удалён.
- Запуск, порты, повторы, полнота и GitHub Actions сохранены.

## 1.7.7

Версия 1.7.6 отдельно не выпускалась; накопленные изменения опубликованы как 1.7.7.

- SQLite переведена на DELETE journal: в базе хранится компактный индекс, полные JSON документов — в отдельных сжатых файлах с чтением по запросу.
- Сохранены полные результаты, потоковый экспорт, контроль полноты и повторы 120 → 24 → 6. Неиспользуемые файлы результатов очищаются без автоматического VACUUM.
- В трее добавлены профили «Минимальный», «Средний», «Высокий», «Максимальный» и сохраняемые ручные настройки параллелизма, памяти и хранения; по умолчанию выбран «Средний».
- Период запроса остаётся ограничен 30 днями; схема трея, диапазон портов и правила GitHub Actions сохранены.
- В EXE, трей и favicon включена пользовательская многоразмерная иконка. Обновлены версия и документация для дальнейшей работы над проектом.

## 1.7.5

- Исправлено исчезновение стрелки у выпадающих списков после первого раскрытия: focus-стиль больше не затирает фоновую SVG-стрелку.
- Переработаны кнопки экспорта CSV/JSON: текст + стандартная SVG-иконка загрузки без символов-стрелок.
- Заголовки таблицы получили непрозрачный фон и больше не накладываются визуально на строки результатов при прокрутке.
- Прокрутка карточки ФД перенесена внутрь содержимого модального окна; scrollbar больше не выходит за границы скругления.
- Карточка ФД очищена: на главном экране оставлены основные данные документа, идентификаторы, место расчётов и данные ФН.
- Добавлен раскрываемый блок **Дополнительные данные ФД**: поступление в ОФД, статусы/код ФНС, внутреннее имя в ОФД и техническая информация.
- Добавлена кнопка **В новой вкладке**: выбранный ФД открывается в отдельной вкладке и автоматически восстанавливается из сохранённого результата.
- Windows-сборка дополнена PE-метаданными версии, manifest `asInvoker`, сборкой без UPX и SHA-256 checksum в Release.
- Release workflow блокирует публикацию тега, если Author/Committer последнего коммита не `4geg` с заданным GitHub noreply email.

## 1.7.4

- Переработана карточка фискального документа: данные сгруппированы по смысловым блокам.
- «Дата/время ККТ» заменено на понятное «Дата и время ФД» с отдельными полями даты и времени.
- «Внутреннее имя» переименовано в «Внутреннее имя в ОФД».
- Значения в карточке копируются нажатием на само поле; у адреса сохранена отдельная кнопка копирования.
- Полный ответ API по умолчанию свёрнут и раскрывается по нажатию.
- Поиск выполняется фоновой задачей приложения: закрытие или обновление вкладки больше не обрывает UI-сессию поиска.
- Последний результат и контекст повтора сохраняются в `last_search.json` и восстанавливаются после повторного открытия интерфейса/приложения.
- Период по умолчанию: с первого числа текущего месяца по текущую дату.
- Лог ограничен примерно 25 МБ: текущий файл до 5 МБ + 4 архива.

- Терминология проекта унифицирована: **фискальные документы**.

## 1.7.1

- Исправлен первый запуск: сервер стартует после инициализации tray-loop, браузер открывается после готовности `/api/health`.
- Перезапуск теперь выполняется внутри текущего процесса без запуска второго onefile-EXE; это устраняет гонки PyInstaller и предупреждение об удалении `_MEI`-каталога.
- Исправлена проверка API-ключа в EXE: CA bundle `certifi` явно включён в сборку и используется `httpx`.
- Успешная авторизация теперь считается достаточной для сохранения ключа; временный сбой получения названия организации больше не отклоняет рабочий ключ.
- Добавлены более точные сообщения об ошибках проверки API-ключа и запись деталей в журнал без логирования самого ключа.
- Добавлена кнопка-глаз для показа/скрытия вводимого API-ключа.

## 1.7.0

- Исправлен Windows launcher: устойчивый запуск веб-сервера, неблокирующее открытие браузера и отзывчивое меню трея.
- Добавлена проверка `/api/health`, резервный локальный порт, журнал/папка данных в меню трея и безопасный перезапуск.
- Веб-интерфейс поиска фискальных документов через Universal API 1-ОФД.
- Раздельные фильтры API-запроса и уже полученных результатов.
- Параллельные запросы, повтор неудачных запросов и контроль полноты.
- Поиск регистраций, перерегистраций, закрытий ФН и других типов ФД.
- CSV/JSON экспорт и просмотр полного ответа API.
- Работа в системном трее: открыть, перезапустить, завершить.
- Несколько сохранённых API-ключей с выбором активного.
- API-ключи шифруются Windows DPAPI и не хранятся в открытом виде.
