1OFD Fiscal Docs — обновление 1.7.1

Если у тебя уже есть локальный репозиторий 1.7.0:
1. Полностью заверши старый EXE через трей или Диспетчер задач.
2. Скопируй файлы из архива обновления в корень проекта с заменой существующих.
3. В VS Code выполни:
   git status
   git add .
   git commit -m "Release 1.7.1"
   git push
4. GitHub -> Actions -> Build Windows EXE -> Run workflow.
5. Скачай новый artifact 1OFD_FiscalDocs-v1.7.1-Windows и проверь EXE.

Пока не создавай тег v1.7.1 до проверки EXE.

Главные исправления:
- первый запуск и автооткрытие браузера;
- restart без запуска второго onefile EXE;
- исправление предупреждения PyInstaller _MEI при перезапуске;
- более надёжная HTTPS-проверка API-key в frozen EXE (certifi);
- глаз для ввода и сохранённых API-ключей;
- единая иконка для EXE и трея.
