# Иконки приложения

Штатный многоразмерный ICO: `assets/app.ico`. Browser favicon: `assets/static/icons/favicon.ico`.

Один квадратный PNG можно конвертировать `tools/make_icon.py`: выходной ICO содержит 16, 24, 32, 48, 64, 128 и 256 px. При передаче PNG также создаются корневая `app.ico` и favicon из того же изображения. Без аргумента генерируется штатная иконка в assets; пользовательская корневая app.ico не меняется.

Корневая app.ico задаёт пользовательскую иконку: build_exe.bat копирует её в оба штатных пути и встраивает в EXE и resource_bundle. Рядом с готовым EXE такая иконка заменяет трей/favicon; значок файла EXE задаётся при сборке.

Без корневой пользовательской иконки используются встроенные ресурсы, распакованные в AppData/resources. Отдельные PNG и отдельный favicon-дизайн для работы не требуются.
